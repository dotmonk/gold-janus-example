# gold-janus-example

Example app: [`gold-janus`](https://github.com/dotmonk/gold-janus) API +
[`janus-elements`](https://github.com/dotmonk/janus-elements) UI (Sunset theme).

## Run (development)

```sh
npm install
npm run dev
```

Then open [http://localhost:3010/](http://localhost:3010/).

One process: `gild({dev:true})` serves `/gold_*`, mounts januse on `frontend/`
(HMR + janus sync), and watches the backend for `tsx watch` restarts.

## Production

```sh
npm start
```

Same origin on [http://localhost:3010](http://localhost:3010). `gild` syncs
janus into `frontend/lib/janus` and serves `frontend/` — no build step. `PORT`
overrides the port. `tsx` runs the backend, so it is a runtime dependency.

## Layout

```
backend/
  index.ts
  api/*Api.ts
frontend/
  *.js                      ← Janus components
  client.js / client.d.ts   ← generated by gold-janus (gitignored)
  lib/janus/                ← synced from janus-elements (gitignored)
  janus-theme-sunset.css
```
